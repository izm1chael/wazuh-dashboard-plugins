# Detection tuning proposal workspace

The incident detail has an on-demand proposal panel for existing triaging, active and closed incidents. It accepts the same paired replay format as the browser-local evaluator, but requires 64-character lowercase SHA-256 baseline/candidate version references and at most 1,000 opaque sample rows. The separate indexer tuning_propose grant and owner check govern creation and withdrawal; tuning_review and independent actor check govern review. The server recomputes the gate and records an immutable audit transition with the fixture fingerprint and counts. The reviewer must repeat the fixture digest and attest independent review. Terminal acceptance means eligible for further human review, not approval to deploy. No rule execution, raw log retention, rule patch or production write. Proposal metadata is shared in the existing single-SOC collaboration projection; ordinary summaries omit it. Historical rule history is separate from this analyst-attested external fixture.
